# API REST - Gestión de Productos

## Descripción
Proyecto desarrollado con Python, Django y Django REST Framework para gestionar productos mediante una API REST.

## Tecnologías utilizadas
- Python
- Django
- Django REST Framework
- SQLite
- Visual Studio Code

## Funcionalidades CRUD
- Registrar productos (POST).
- Consultar productos (GET).
- Actualizar productos (PUT y PATCH).
- Eliminar productos (DELETE).

## Dirección de la API
http://127.0.0.1:8000/api/productos/
